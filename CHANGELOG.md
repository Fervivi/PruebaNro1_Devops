# Changelog

En este archivo se registran los cambios importantes realizados en el proyecto.

## [0.2.0] - 2026-09-05

### Agregado

- Creación de ramas `feature` para simular desarrollo colaborativo.
- Creación de rama `hotfix` para simular una corrección.
- Registro de cambios mediante commits descriptivos.
- Integración de cambios mediante pull requests.
- Documentación del flujo de trabajo con ramas `main`, `dev`, `feature` y `hotfix`.
- Archivo `CODE_OF_CONDUCT.md` con normas de colaboración del proyecto.

### Modificado

- Actualización del sitio web para mostrar visualmente el flujo DevOps.
- Mejora de estilos del sitio mediante el archivo `assets/style.css`.
- Actualización de la documentación para describir el uso de Git, GitHub y GitHub Actions.

## [0.1.0] - 2026-09-05

### Agregado

- Creación inicial del repositorio.
- Estructura base del sitio web.
- Archivo `index.html` como página principal.
- Carpeta `assets` para organizar estilos y scripts.
- Archivo `assets/style.css` para los estilos del sitio.
- Archivo `assets/app.js` para futuras funciones JavaScript.
- Configuración inicial de GitHub Actions.
- Workflow para despliegue automático hacia servidor EC2.
- Archivo `README.md` con descripción general del proyecto.
- Archivo `CONTRIBUTING.md` con guía de contribución.
- Archivo `LICENSE.md` con licencia del proyecto.

### Documentado

- Estrategia de ramificación.
- Convención de nombres de ramas.
- Convención de commits.
- Flujo de trabajo con pull requests.
- Descripción general del proceso de despliegue.
