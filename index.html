GitHub Actions + AWS EC2

Flujo DevOps Automatizado

Esta página demuestra un despliegue automático: cada cambio enviado a la rama principal activa el workflow, copia los archivos al servidor y publica la nueva versión en Apache.

Pipeline

Del repositorio al servidor

1

Cambio local

Se modifica el HTML, CSS o JavaScript del proyecto.

2

Push a GitHub

Los cambios se suben a la rama main.

3

GitHub Actions

El workflow prepara la conexión SSH y copia los archivos.

4

Servidor EC2

La instancia recibe el sitio dentro de una carpeta temporal.

5

Apache

Los archivos se publican en /var/www/html.

Objetivo del proyecto

Practicar un flujo DevOps real usando control de versiones, automatización, conexión remota por SSH y despliegue en un servidor web.
